# HSBC Personal Loan Acceptance Analysis

## 📌 Project Overview

This project analyzes HSBC customer data to identify the factors influencing personal loan acceptance. Using Microsoft Excel, the project applies data cleaning, exploratory data analysis (EDA), pivot tables, charts, and dashboard visualization to uncover customer behavior patterns and provide actionable business recommendations.

The primary objective is to help the bank improve marketing efficiency by identifying customer segments that are most likely to accept personal loan offers.

---

## 🎯 Objectives

* Analyze customer demographics and financial characteristics.
* Identify key factors influencing personal loan acceptance.
* Create an interactive Excel dashboard for business insights.
* Measure loan acceptance rates using KPIs.
* Provide recommendations to improve future marketing campaigns.

---

## 📂 Dataset

The dataset contains customer information, including:

* Customer ID
* Age
* Income
* Family Size
* Education Level
* Mortgage
* Credit Card Usage
* Online Banking Usage
* Securities Account
* CD Account
* Personal Loan Status

## 🔍 Key Insights

* Higher-income customers are more likely to accept personal loans.
* Customers with higher education levels show greater acceptance rates.
* Online banking users demonstrate increased engagement with loan offers.
* Customer segmentation enables more targeted and cost-effective marketing campaigns.

---

## 💡 Business Recommendations

* Focus marketing efforts on high-income customer segments.
* Target customers with postgraduate and professional education.
* Promote digital banking services to improve customer engagement.
* Use customer segmentation to reduce marketing costs and improve campaign performance.
